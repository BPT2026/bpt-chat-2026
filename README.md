# BPTChat - Real-time Chat Application

A WhatsApp-like chat application built with React (frontend), Python (backend), MongoDB (database), and WebSockets (real-time communication).

## Features

✅ User Authentication (Registration & Login)
✅ Real-time Messaging with WebSockets
✅ Contact Management
✅ Message Notifications
✅ Chat History
✅ Media Sharing (5MB max per file)
✅ Responsive Web UI

## Tech Stack

**Frontend:** React, Socket.io-client, Axios
**Backend:** Python, Flask, Flask-SocketIO, PyMongo
**Database:** MongoDB
**Real-time Communication:** WebSockets

## Getting Started

### Prerequisites
- Node.js (v14+)
- Python (v3.8+)
- MongoDB

### Installation

**Frontend:**
```bash
cd frontend
npm install
npm start
```

**Backend:**
```bash
cd backend
pip install -r requirements.txt
python app.py
```
